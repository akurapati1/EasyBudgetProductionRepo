# EasyBudget client

React 18 single-page app (Create React App). See the [root README](../README.md) for setup, Docker and API details.

```bash
npm install
cp .env.example .env     # REACT_APP_API_URL
npm start                # dev server on :3000
npm test                 # Jest + Testing Library
npm run build            # production bundle in build/
```
